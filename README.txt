나의 산수 선생님 V1.0

구성: index.html (단일 파일, 별도 서버·AI·API 키 불필요)

사용 방법:
1. GitHub 저장소에 index.html을 업로드합니다.
2. Settings > Pages에서 Deploy from a branch, main, /(root)를 선택합니다.
3. Pages 주소를 iPad의 Safari로 열고 '공유 > 홈 화면에 추가'를 선택합니다.
4. 앱에서 '설명 듣기' 또는 설정의 '목소리 시험'을 눌러 한국어 음성을 시작합니다.

지원 기능:
- 자릿값/계산 순서 설명, 두 자리 덧셈(받아올림 전후), 뺄셈(받아내림 전후)
- 단계별 풀이, 한국어 TTS 음성 설명, 다시 듣기·느리게 말하기
- 각 단계에서 직접 답 고르기, 오답 힌트, 비슷한 문제로 연습
- 기기 내 학습 기록 및 JSON 백업/복원

주의사항:
- 실시간 자유 대화 AI와 음성인식 질문은 포함하지 않았습니다. '다시 설명해줘'는 현재 단계의 준비된 보충 설명입니다.
- 음성 합성은 브라우저/기기의 한국어 음성 지원에 따라 달라지며 첫 재생은 사용자가 버튼을 눌러야 할 수 있습니다.
- 학습 기록은 localStorage에 보관됩니다. 홈 화면 앱과 Safari는 저장소가 분리될 수 있습니다.
