수학선생님 V3.1

수정: 함께 풀기의 질문-응답 대기 루프 분리, 정답 판정 후 다음 질문 이동, 음성 문장 끝 표현 정리(입니다), 수업 기록 유지.

수학선생님 V3.0 — GitHub Pages 업로드용

업데이트 방법
1. ZIP 파일의 압축을 풉니다.
2. index.html, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png를 기존 GitHub Pages 저장소 최상위에 업로드(덮어쓰기)합니다.
3. Safari에서 기존 주소에 ?v=30을 붙여 새 버전을 확인합니다.
4. 저장된 홈 화면 앱을 다시 열어도 같은 사이트의 학습 기록을 이어받습니다.

새 구조
- 숫자가 나타나는 화면 상태와 짧은 음성 문장을 하나의 진행표(큐)에서 제어합니다.
- 강의를 한 칠판에서 진행하며 완성된 계산식을 유지하고 마지막에는 강조 복습을 합니다.
- 잠시 멈추기 후 이어서 듣기는 현재 짧은 설명부터 재생됩니다(iOS 음성 합성기 제한 대비).
- 한국어 숫자 뒤 잠깐 쉬는 옵션을 기본 켰습니다. 음성 설정에서 끌 수 있습니다.
- 기존 math-teacher-v1 로컬 학습 기록 키를 그대로 사용합니다.

주의
- iPad/iPhone Safari의 음성 합성 품질과 재생 동작은 iOS 버전에 따라 다릅니다.
- 안정된 음성 사용을 위해 사용자가 직접 강의 듣기 버튼을 눌러 시작합니다.
- 서버나 외부 AI 연결 없이 브라우저의 기기 음성 합성을 사용합니다.
