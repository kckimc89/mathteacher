V3.16 변경사항
- 기존 '선생님 강의', '함께 풀기' 외에 독립적인 '혼자 풀기' 버튼 제공.
- 함께 풀기와 마지막 복습 완료 후 자동으로 같은 문제를 혼자 풀어보도록 연결.
- 처음부터 설명 없이 새 문제로 혼자 풀기도 선택 가능.
- 0~9 숫자판, 자리별 두 칸/한 칸, 지우기, 정답 확인.
- 3번까지 답을 다시 입력하고 평가. 세 번째 오답 후 정답을 공개하고 다시 듣기/새 문제 선택.
- 정답 시 축하 및 별 표시. 새 문제는 같은 단계의 새로운 숫자로 자동 생성.
- 혼자 푼 문제 수, 성공 수, 첫 도전 정답 수, 복습 필요 수 기록. 기존 기록과 음성 설정 보존.

참고: 음성 합성 결과와 iPad Safari의 실제 동작은 기기에서 추가 점검이 필요합니다.

V3.17 변경사항
- 혼자 풀기에서 가로셈 / 세로셈 / 섞어서 선택 가능
- 섞어서: 새 문제마다 가로셈과 세로셈을 번갈아 제시
- 두 형태 모두 십의 자리/일의 자리 답칸과 숫자판 입력, 3회 도전 유지
- 기존 저장 기록 보존, 사용자가 고른 출제 모양 저장
