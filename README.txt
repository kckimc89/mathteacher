수학선생님 V3.5

V3.4의 학교식 가로셈에 받아올림/받아내림 설명을 보강했습니다.
예: 27+15 → 27+10=37 → 7+5=12 → 12=10+2 → 30+10+2=42.
예: 42-17 → 42-10=32 → 32=20+12 → 12-7=5 → 20+5=25.
「함께 풀기」에서는 일의 자리 계산 질문에 답하기 전 결과를 노출하지 않습니다.
기존 앱의 네 가지 풀이 방법, 같은 문제 비교, 음성/학습기록 저장 구조를 유지합니다.
GitHub Pages의 기존 저장소에 모든 파일을 업로드하세요. Safari에서 ?v=35로 새로 확인할 수 있습니다.
실기기 Safari 음성의 실제 타이밍은 별도 검증이 필요합니다.
