수학선생님 V2.4

수정 사항
- 1단계 「자릿값과 순서」에서도 일의 자리 답과 십의 자리 답을 실제로 표시합니다.
- 1단계의 마지막 화면은 반드시 완성된 계산 결과를 보여줍니다.
- 1단계 예시에서 받아올림이 생기면 작은 1과 최종 십의 자리 숫자도 올바르게 계산하고 표시합니다.
- 모든 학습 단계의 마지막 화면에서 일의 자리 및 십의 자리 정답이 빠지지 않도록 안전 처리를 추가했습니다.
- 기존 선생님 설명 / 함께 풀기 / 연속 음성 / 기록 / 아이콘은 유지했습니다.

검증: 9개 학습 단계의 40개 예제에 대해 각 단계의 정답 선택,
완성 화면의 계산 결과, 모의 음성 이벤트로 연속 설명 완료를 확인했습니다.
실제 아이패드 Safari의 음성 및 화면 동기화는 별도 확인이 필요합니다.

업로드: 압축을 푼 모든 파일을 기존 GitHub Pages 저장소에 업로드하세요.
Safari 확인: 기존 주소 끝에 ?v=24 를 붙여 새 버전을 확인하세요.
