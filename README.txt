수학선생님 V1.2

기존 V1.0을 대체하는 GitHub Pages 업로드 패키지입니다.
index.html, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png 모두 저장소의 같은 위치에 업로드하세요.

추가 학습: 한 자리 덧셈/뺄셈, 두 자리 + 한 자리, 두 자리 - 한 자리. 기존 두 자리 덧셈/뺄셈은 유지합니다.
변경: 선택형 문제 정답 판정 수정, 앱 이름과 홈 화면 아이콘 변경.
기존 학습기록 localStorage 키 유지. 단, 배포 주소가 바뀌면 브라우저 기록이 자동 이전되지는 않습니다.

아이패드: Safari에서 GitHub Pages 주소를 열고 공유 > 홈 화면에 추가.
음성: 기기 내장 speechSynthesis 사용, 한국어 음성 지원 여부에 따라 동작 차이가 있을 수 있습니다.

V1.2 수정: 계산 순서 질문의 선택지 인덱스 정답 판정과 숫자형 선택지 정답 판정을 분리했습니다. 기존 학습 기록(localStorage)은 그대로 유지합니다.
