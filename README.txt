수학선생님 V2.3

개선 사항
- 「선생님 설명 → 처음부터 연속 설명 듣기」에서 문장과 쉼표를 실제 음성 구간으로 분리합니다.
- 각 음성 구간이 끝나면 설정한 설명 사이 간격에 따라 쉬었다가 다음 구간을 읽습니다.
- '일의 자리 아래에 3을 적어요', '십의 자리 위에 작은 1을 적어요'처럼 숫자 적기를 설명한 구간이 끝나면, 해당 숫자를 그때 화면에 나타냅니다.
- 기존 두 모드(선생님 설명/함께 풀기), 9개 학습 단계, 한국어 음성 설정, 홈 화면 아이콘 및 기록 저장 방식을 유지합니다.
- 아이패드 Safari에서 소리가 시작되지 않는 경우 오류 안내를 표시합니다.

업로드: 압축을 풀어 나온 전체 파일을 기존 GitHub Pages 저장소에 업로드합니다.
확인: 기존 주소에 ?v=23 을 붙여 Safari에서 새 버전이 표시되는지 확인합니다.

주의: 자바스크립트 문법과 모의 음성 이벤트 기반 자동 진행 검사는 통과했으나, 실제 아이패드에서의 음성 이벤트/정지 시간은 기기별로 확인해야 합니다.
