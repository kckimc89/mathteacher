수학선생님 V3.6 — 학교식 가로셈과 숫자 음성 개선

- 학교식 가로셈의 받아올림을 십 단위 합산과 남은 일의 자리 합산으로 분리
- 27+15: 15=10+5 → 27+10=37 → 7+5=12 → 12=10+2 → 30+10=40 → 40+2=42
- 「함께 풀기」에서 십 단위 합산 및 마지막 합산에 답을 기다리는 질문 추가
- 숫자 뒤에 '입니다'가 올 때 숫자 발화와 어미 발화를 분리하고 짧은 실시간 간격 적용
- 숫자 발화는 약간 느리고 또렷하게 재생하도록 시도 (기기 음성 합성 품질에 따라 차이)
- 기존 9개 단계, 네 가지 풀이 방법, 같은 문제 비교, 앱 아이콘, 저장된 학습 기록 유지
